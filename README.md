Adult Dataset using Decision Tree

This is a simple Machine Learning project using the Adult dataset from the UCI Machine Learning Repository.

The aim is to predict a person’s income class (<=50K or >50K) using a Decision Tree Classifier.

How it works

1. Load the Adult dataset.
2. Remove missing values.
3. Convert text data into numbers.
4. Split the data into training and testing data.
5. Train the Decision Tree model.
6. Predict the income using test data.
7. Calculate the accuracy.

How to Run

First install the required libraries:

pip install pandas scikit-learn

Then run:

python adult_decision_tree.py

On Mac/Linux, you can also use:

python3 adult_decision_tree.py

The program will show the accuracy in the terminal.
